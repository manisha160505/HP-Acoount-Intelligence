We understand that the requirements document shared earlier provides, for each feature, details around what data is required, where that data comes from, and how it should be cleaned and prepared. However, from the pipeline implementation perspective, the upstream sources themselves are not our primary concern.

The exhaustive set of final cleaned datasets that will be fed into the pipeline for that account.

The different datasets/files/tables/objects that make up the input for an account

Their schemas and key fields

Relationships between the datasets

Identifiers and keys used to link records across datasets

Any standard values, statuses, scores, evidence objects, metadata, or other conventions that form part of the expected input

A direct and explicit mapping of the input data to the 11 in-scope features and their outputs.
